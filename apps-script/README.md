# Apps Script 적용 안내 (사진 첨부 · 메일 알림)

웹페이지(`index.html`)만 바꿔서는 켤 수 없는 기능이 두 가지 있습니다. 이 폴더의 `Code.gs` 를 Apps Script 에 적용하면 켜집니다.

| 기능 | 웹페이지 | Apps Script |
|---|---|---|
| 사진 첨부 | 준비 완료 (`doGet?action=features` 응답이 오면 «사진 추가» 버튼이 자동으로 나타남) | `Code.gs` 적용 필요 |
| 메일 알림 | 화면 상단 «확인 필요» 알림은 이미 동작 | `sendReminders` 트리거 설정 필요 |

## 적용 순서
1. 구글 시트 → 확장 프로그램 → Apps Script 에서 **기존 코드 전체를 복사해 따로 보관**합니다.
2. `Code.gs` 내용으로 교체합니다. (`SHEET_NAME` 이 기존 시트 탭 이름 `_WEBDATA` 와 같은지 확인)
3. 저장 후 편집기에서 `upload_` 가 쓰는 Drive 권한을 승인합니다 (아무 함수나 한 번 실행하면 권한 요청 창이 뜹니다).
4. 배포 → 배포 관리 → 편집 → 버전 «새 버전» → 배포. 액세스 권한은 «링크가 있는 모든 사용자» 그대로 유지합니다.
5. 메일 알림: 프로젝트 설정 → 스크립트 속성에 `REMIND_TO` = `담당자1@..., 담당자2@...` 를 추가하고, 트리거 → 함수 `sendReminders` → 시간 기반 → 일 단위(오전)로 추가합니다.

## 배포 후 점검표
- [ ] 페이지에서 월 탭 이동·입력·저장이 이전처럼 되는지
- [ ] 이슈 유형 입력 시 «사진 (배송누락, 파손 등)» 영역에 «사진 추가» 버튼이 보이는지
- [ ] 사진을 올리면 Drive 의 `풀무원샘물_배송사진` 폴더에 파일이 생기고 썸네일이 보이는지
- [ ] `sendReminders` 를 한 번 직접 실행했을 때 지연 건이 있으면 메일이 오는지

## 안전장치(코드에 포함)
- 저장 키는 `pulmuone-water:YYYY-MM` 형식만, 값은 49,000자 이하만 받습니다.
- 동시에 저장해도 서로 섞이지 않도록 한 번에 하나씩 처리합니다 (`LockService`).
- 사진은 링크를 아는 사람만 볼 수 있게 공유되며, 1장 6MB(변환 후) 이하만 받습니다.
